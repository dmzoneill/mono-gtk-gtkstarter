# GtkStarter

A minimal C++ starter project set up to build against gtkmm.

## What it does

`GtkStarter.cpp` includes `gtkmm.h` and prints a message. It is a template for
checking that a gtkmm build works, not a full application.

## Tech

- C++ with gtkmm 2.4
- Eclipse CDT project and a Makefile

## Building

```sh
make
./GtkStarter
```
